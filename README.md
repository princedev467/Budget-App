# 💰 Budget App

A simple and responsive **Budget Management Web Application** built using **HTML, CSS, and JavaScript** to help users manage their income and expenses efficiently.

It allows users to track transactions, calculate balance instantly, and manage budgets with a clean and user-friendly interface.

---

## 🚀 Live Demo

🔗 https://princedev467.github.io/Budget-App/

---

## ✨ Features

- ➕ Add Income & Expenses
- 📊 Real-Time Balance Calculation
- 🧾 Transaction History
- ❌ Delete Transactions
- 💻 Responsive Design
- ⚡ Fast & Lightweight
- 🎯 Simple UI/UX
- 💾 Local Storage Support
